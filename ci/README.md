# App native framework producer

`nice -n 15 bash ci/native-frameworks.sh PRODUCT` builds one of `helix`, `fd`, `fzf`, `navi`, `gitoxide`, `Ruff`, `rg`, or `node` on an Apple silicon Mac with Xcode 26.3, uv, and the toolchain pinned by that product's recipe. The Actions workflow provisions Rust 1.96.1, Rust 1.99.0 for Ruff, or Go 1.27.2 for fzf. Node needs Python 3.10-3.14 and npm. Compilation uses at most four jobs.

The producer calls the existing source recipes and patches. Each recipe verifies its source archive checksum; Cargo lockfiles and Go module checksums retain their dependency verification. A checksum-pinned public ios_system revision supplies the link dependency, independently of local framework caches. Each product contains exactly an arm64 device slice and a universal arm64/x86_64 Simulator slice. Builds target iOS 14.0, or 16.0 for Node. Shipped artifacts use size optimization and symbol stripping; each product includes stripped and gzip byte counts. The final ZIP passes SHA256/SwiftPM, architecture, platform, minimum OS, command export and dependency-path checks before upload. Compilation and artifact checks do not establish app or phone behavior.

Node also needs Rosetta 2 for its x64 build-time generators. The producer refreshes `Resources/npm` and `Resources/node-fetch` and produces `node-npm.zip` and `node-fetch.zip`. Extract these into the app's `Resources/npm` and `Resources/node-fetch` respectively. JavaScript stays outside `node.xcframework`, matching the existing app packaging recipe. Intermediate Node frameworks stay under `.build`; the app's existing `xcfs/node.xcframework` is preserved.

Pull requests and manual runs retain the eight framework ZIPs, audit reports, checksum manifests and release notes as Actions artifacts. Tags beginning with `native-` also trigger a build. Only tags in `holzschu/a-shell` can publish releases; auxiliary releases leave the repository's latest release unchanged. Existing release assets are never overwritten. Consumer URLs and checksums must come from a downloaded upstream release, after publication and verification.
